This game is about defending yourseft from a hoard of other circles!
You can buy upgrades to make yourself stronger!
Other circles' speed scale with total money.
There's even a settings menu.
```mermaid
flowchart TD
    A[Start] --> B[Play]
    B --> C[Get money]
    C --> F[Buy upgrades from the shop]
    F --> B
    C --> D[Have Fun!]
```
